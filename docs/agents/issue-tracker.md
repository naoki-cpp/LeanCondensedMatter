# Issue tracker: GitHub

Issues for this repository live in GitHub Issues at `naoki-cpp/LeanCondensedMatter`.
Use the `gh` CLI from the repository checkout for issue operations.

## Pull requests as a request surface

No. External pull requests are not triaged as feature requests.

## Operations

- Create: `gh issue create --title "..." --body "..."`
- Read: `gh issue view <number> --comments`
- List: `gh issue list --state open`
- Comment: `gh issue comment <number> --body "..."`
- Edit labels: `gh issue edit <number> --add-label "..."`
