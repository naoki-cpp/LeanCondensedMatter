# Domain docs

Start with the root [context map](../../CONTEXT-MAP.md) to identify the relevant
domain and its language sources. The repository contains several contexts;
[CONTEXT.md](../../CONTEXT.md) defines the narrower finite-cutoff MassiveDirac
transport vocabulary.

Read the relevant architecture notes and [architecture decisions](../../doc/adr/README.md)
for the chosen context. The [documentation guide](../README.md) groups the
available models, glossaries, examples, and roadmaps by purpose.

Use the relevant glossary's canonical terms in issue titles, refactor plans,
and tests. If a term is missing, resolve it through domain modeling before
introducing a new synonym.
