# Separate diagram combinatorics, physical amplitudes, and convergence

Put finite partitions, pairings, and generic connected-decomposition mathematics in Combinatorics. Common diagrammatics owns many-body diagram structure, component restriction and reassembly, and ordering; statistics-specific layers supply pair values, signs, and physical amplitudes.

This allows shared component arguments without importing fermionic thermal semantics into generic combinatorics. Ordering is mathematical data when crossing parity matters, so reindexing must preserve or explicitly transport that information rather than use an arbitrary finite-type equivalence.

Keep formal power-series identities separate from analytic statements about convergent expansions. A formal linked-cluster identity does not authorize evaluation of its series at a physical parameter. Analytic endpoints add the required finite-dimensional, integrability, or convergence hypotheses. The two-point expansion's Semantics → Factorization → Analysis → Integration → Series layering makes these responsibilities explicit.

Evidence: [connected-decomposition mathematics](../../LeanCondensedMatter/Combinatorics/Cumulant/ConnectedDecomposition.lean), [generic external-insertion diagrams](../../LeanCondensedMatter/SecondQuantization/Common/Diagrammatics/ExternalInsertion/Core/Diagram.lean), [two-point diagrams](../../LeanCondensedMatter/SecondQuantization/Common/Diagrammatics/TwoPoint/Core/Diagram.lean), [diagrammatics architecture](../../notes/architecture/second-quantization.md), [layer graph](../../scripts/architecture/second_quantization.json), and [analytic linked-cluster endpoint](../../LeanCondensedMatter/SecondQuantization/Fermionic/Diagrammatics/LinkedCluster/Analytic.lean).

## Historical evidence

[Issue #1267](https://github.com/naoki-cpp/LeanCondensedMatter/issues/1267) keeps arbitrary even-external-insertion diagrams in an independent Common representation, reusing perfect pairings without migrating the mature TwoPoint API or adding a bridge before a concrete consumer needs one. It distinguishes vacuum-free correlation (every component meets an external insertion, while several such components may remain) from full external connectedness, which is selected only by a later cumulant/source layer. Thus vacuum normalization alone does not imply connectedness for higher-point functions; odd external sectors and analytic convergence remain separate concerns. The issue is still open, so this records the implemented data and semantic boundaries, not completion of its amplitude or cumulant theorems.

[Issue #894](https://github.com/naoki-cpp/LeanCondensedMatter/issues/894) settled the external-leg two-point LCT on a binary external-slot fiber split: one externally connected piece and one aggregate vacuum piece. Because the ordered simplex couples interaction times, the coefficient product is established after summing the finite slot interleavings with the measurable binary-shuffle theorem; do not assume a per-diagram product over connected components or force this theorem through the general `Finpartition` cumulant framework. The resulting coefficient convolution is canceled using the existing constant-coefficient normalization API. The general n-ary shuffle result remains reusable infrastructure, while this theorem consumes the binary specialization.

[Issue #893](https://github.com/naoki-cpp/LeanCondensedMatter/issues/893) applied the a.e. LCT route to module ownership: retain public mathematics, genuinely reusable `Analysis`/`Combinatorics` results, and the compact covariance needed under the integral; fold or delete one-purpose transport layers and import authoritative owner modules from the public umbrella. Exact coincidence-wall covariance and compatibility forwarders are not obligations when downstream integration only needs the off-diagonal result.

[Issue #877](https://github.com/naoki-cpp/LeanCondensedMatter/issues/877) gives the finite-family shuffle one ambient-cardinality representation with shared `slotEquiv` and per-fiber order embeddings. Quartic and TwoPoint component shuffles specialize that structure instead of duplicating fields, Fintype/extensionality proofs, and `Fin.castOrderIso` transports; domain theorem statements remain intact.

[Issue #853](https://github.com/naoki-cpp/LeanCondensedMatter/issues/853) implements the finite mixed-event order with Mathlib sorting over the proved stable event relation, deleting a local insertion-sort algorithm and duplicated correctness proofs. The physical tie/order convention and downstream ordered-event API remain unchanged; reuse standard algorithms without altering domain semantics.

[Issue #824](https://github.com/naoki-cpp/LeanCondensedMatter/issues/824) generalizes the family-shuffle product theorem to arbitrary finite index types, using `Fintype.equivFin` only inside the generic proof. Quartic and TwoPoint consumers now pass their component-part types directly; domain layers no longer enumerate `Fin k` and transport dependent shuffle data back and forth.

[Issue #822](https://github.com/naoki-cpp/LeanCondensedMatter/issues/822) keeps one substantive finite-family shuffle induction at the measurable-locally-bounded boundary. The continuous API is a bridge to that general theorem, not a second induction with stronger hypotheses.

[Issue #802](https://github.com/naoki-cpp/LeanCondensedMatter/issues/802) extends the Quartic subtree to component partition, restriction, connectivity, decomposition, and reassembly modules, deleting the old flat paths after imports move. Two-point restriction depends on the quartic syntax it actually constructs, not on the quartic component-restriction implementation; ownership cleanup follows real declaration dependencies without changing diagram semantics.

[Issue #782](https://github.com/naoki-cpp/LeanCondensedMatter/issues/782), completed by #785, regrouped the Common diagram API by domain under `Diagrammatics/Quartic` and `Diagrammatics/TwoPoint`. Quartic syntax belongs under the Quartic subtree, and two-point syntax imports its actual generic dependencies rather than quartic diagram syntax. File moves are breaking when ownership changes; old flat paths are removed instead of forwarded.

[Issue #779](https://github.com/naoki-cpp/LeanCondensedMatter/issues/779) removes only the unused diagram-specific binary `TwoComponentOrderedSimplex` layer. [Issue #767](https://github.com/naoki-cpp/LeanCondensedMatter/issues/767) uses the finite order-signature partition to obtain a measurable locally bounded canonical component amplitude, then supplies the ordered-simplex integrability input. [Issue #756](https://github.com/naoki-cpp/LeanCondensedMatter/issues/756) transports ambient component-factor measurability to the canonical localized integrand by composing with a continuous dependent-slot embedding and coordinate map. [Issue #748](https://github.com/naoki-cpp/LeanCondensedMatter/issues/748) fixes the lasting module split: `Combinatorics.PerfectPairing` owns scalar evaluation and pairing-induced graph connectivity; `Common.Diagrammatics` groups only Quartic and TwoPoint domain structures. [Issue #745](https://github.com/naoki-cpp/LeanCondensedMatter/issues/745) upgrades chamberwise continuity to global measurability by taking a finite sum over order signatures and selecting each chamber's continuous representative on its Borel fiber. The finite partition includes wall points according to the deterministic stable-order convention. This proves measurability without claiming global continuity across walls or requiring an infinite chamber cover.

[Issue #738](https://github.com/naoki-cpp/LeanCondensedMatter/issues/738) turns the mixed-order chamber decomposition into an a.e. analytic tool by proving the finite union of interaction/external-time and distinct interaction-time hyperplanes is null in `Fin n → ℝ`. This justifies ignoring order walls for almost-everywhere regularity while retaining the deterministic equal-time convention in pointwise definitions.

[Issue #732](https://github.com/naoki-cpp/LeanCondensedMatter/issues/732) packages chamberwise continuity by freezing the dependent finite-pair index and crossing weight at a base time assignment, then varying only globally continuous fixed-standard-leg contractions. The resulting ordinary continuous representative agrees with the true component factor on its order chamber. This avoids claiming continuity for an expression whose subtype/index itself changes with the parameters.

[Issue #723](https://github.com/naoki-cpp/LeanCondensedMatter/issues/723) isolates continuity at the fixed-leg scalar kernel: express a finite-Gibbs pair contraction as two imaginary-time exponential factors times a time-independent bare expectation, which makes it jointly continuous in the field times. This analytic primitive is global for a fixed pair of standard legs; combinatorial transport of normalized pairs across chambers remains a separate argument.

[Issue #720](https://github.com/naoki-cpp/LeanCondensedMatter/issues/720) separates the combinatorial part of component locality from its analytic factor: normalized endpoints and fermionic crossing data are invariant as interaction times vary within one `SameTwoPointOrderChamber`, without requiring exact component-time equality. Chamber geometry handles transport; finite-Gibbs contraction continuity and integration across chamber walls remain separate obligations.

[Issue #719](https://github.com/naoki-cpp/LeanCondensedMatter/issues/719) identifies the shared diagram boundary as a scalar pairing evaluator with an explicit pair kernel and global weight. Vacuum quartic, fermionic external two-point, and bosonic coefficientwise amplitudes can reuse it without a universal thermal-state abstraction or a forced common insertion geometry. The canonical finite-fermion kernel comes from the density-state expectation; coordinate Gibbs sums remain downstream calculation infrastructure. Redundant public raw-weight and parallel-density APIs were removed after migration.

[Issue #704](https://github.com/naoki-cpp/LeanCondensedMatter/issues/704) makes the analytic integration boundary precise for component amplitudes: prove continuity on strict-order chambers, global measurability and compact-box bounds, then ordered-simplex integrability under the actual finite-mode assumptions. The component-shuffle theorem needs only measurable, locally bounded integrands; false global continuity across time-order walls is unnecessary. The remaining integrated reindex/covariance step was split from regularity and ultimately uses the a.e./null-diagonal route recorded in #434.

[Issue #698](https://github.com/naoki-cpp/LeanCondensedMatter/issues/698) proves pointwise component locality by showing that `ComponentTimeEq` preserves transported endpoint fields, endpoint times, and their finite-Gibbs contraction. Combined with the crossing-locality result, this removes caller-supplied geometric hypotheses from the component pairing and Dyson fixed-time factorization. It is still a pointwise/canonical-shuffle result; integrated factorization waits for its own continuity and integrability proof.

[Issue #463](https://github.com/naoki-cpp/LeanCondensedMatter/issues/463) established `Analysis.Dyson` as the owner of the state-independent bounded Dyson–Volterra theory: recursive coefficients, factorial majorants, norm convergence, justified series/integral exchange, the Volterra equation, uniqueness, and the constant-generator exponential bridge. Finite SecondQuantization code now specializes this core; only matrix-coefficient reconstruction from algebraic Fock space remains finite-specific. The migration was intentionally breaking, deleting obsolete finite-only wrappers and imports after callers moved.

[Issue #434](https://github.com/naoki-cpp/LeanCondensedMatter/issues/434) closes the finite-mode normalized two-point linked-cluster route with two external legs: component factorization is integrated using injective-time covariance and an almost-everywhere null-diagonal argument, then a single finite-sum reindex gives coefficient convolution and formal vacuum-series cancellation. The public endpoint is the canonical connected/no-vacuum-component predicate. Exact equal-time covariance, per-diagram orbit bookkeeping, and a general source-functional layer were explicitly rejected as unnecessary for this result; proof-internal transport APIs were allowed to break. [Issue #819](https://github.com/naoki-cpp/LeanCondensedMatter/issues/819) records why: the integral needs covariance only off the coincidence diagonals, so stronger pointwise transport there was abandoned.

[Issue #433](https://github.com/naoki-cpp/LeanCondensedMatter/issues/433) adds explicit orders one through three as readable regression corollaries of the finite-mode fermionic linked-cluster theorem. Their subtraction terms expose disconnected-contribution cancellation and lock the factorial, sign, and normalization conventions across the formal logarithm and analytic logarithmic derivatives. These examples validate the existing bridge; they do not define a second convention or replace the general theorem.

[Issue #432](https://github.com/naoki-cpp/LeanCondensedMatter/issues/432) documents the final external-leg linked-cluster route: ordered-simplex and measurable-shuffle products with formal vacuum-series cancellation. It explicitly superseded a stronger exact equal-time covariance route. Preserve the proved route and its finite-mode scope; do not revive a mathematically stronger-looking construction whose required identities were not the final implementation.

[Issue #312](https://github.com/naoki-cpp/LeanCondensedMatter/issues/312) completes the boundary chain by choosing a local analytic logarithm of the normalized partition function near zero, matching its Taylor coefficients to the formal logarithm, and converting factorial-scaled coefficients to derivatives. The order-zero term is excluded explicitly. This composition consumes the established connected-amplitude theorem and does not redefine its sign, coupling, or factorial conventions.

[Issue #311](https://github.com/naoki-cpp/LeanCondensedMatter/issues/311) requires identifying the already convergent Dyson partition series with the Taylor series of the finite-dimensional analytic trace of the interacting exponential. Moving the sum through the trace and proving local nonvanishing are separate obligations: the former identifies coefficients, and the latter permits an analytic logarithm near zero. The formal coefficient normalization remains unchanged across this bridge.

[Issue #310](https://github.com/naoki-cpp/LeanCondensedMatter/issues/310) requires identifying the analytic Dyson evolution with the interaction-picture exponential through derivative/initial-value uniqueness, for arbitrary finite-mode interaction. Commutation of the free Hamiltonian and interaction is only a regression case, not a proof hypothesis. The ordered product `exp(τ H₀) · exp(-τ(H₀ + λV))` must preserve the same composition convention as the Dyson coefficients.

[Issue #309](https://github.com/naoki-cpp/LeanCondensedMatter/issues/309) drew the boundary between a formal Dyson series and an analytic evolution: the sum must converge as a continuous operator, the series–integral interchange must be justified, and the resulting evolution must satisfy its Volterra equation and initial condition. Only after those facts may coefficient recursion be used as an analytic evolution law.

[Issue #308](https://github.com/naoki-cpp/LeanCondensedMatter/issues/308) chose sufficient uniform operator-norm bounds and a factorial majorant to prove local uniform and absolute convergence of the finite-mode Dyson series. Sharp constants were explicitly unnecessary: the theorem needs a reusable summable bound for later analytic identification, with assumptions on inverse temperature, time, and coupling made explicit. This keeps estimates proportionate to their role in the proof.

[Issue #306](https://github.com/naoki-cpp/LeanCondensedMatter/issues/306) specifies how the formal finite-mode linked-cluster theorem crosses into analysis: first establish a continuous-operator realization, then coefficient bounds, convergent Dyson evolution, the operator-exponential identity, the partition-function Taylor series, and finally the log-derivative theorem. It gates this sequence on a Mathlib/API preflight and Common-layer extraction. The staged order keeps convergence and operator semantics out of the formal combinatorial result, and makes the finite-dimensional scope explicit at each bridge.

[Issue #298](https://github.com/naoki-cpp/LeanCondensedMatter/issues/298) explicitly limited the composed Dyson linked-cluster endpoint to formal power series: no convergence, thermodynamic limit, or identification with an analytic interacting partition function followed from that result. This is a recorded scope decision behind the separate analytic layer, not merely a caution inferred from the present code.

[Issue #294](https://github.com/naoki-cpp/LeanCondensedMatter/issues/294) placed exponential-generating-function normalization in a generic formal-log/cumulant bridge: for a series with constant coefficient one, the positive-degree log coefficient multiplied by `n!` matches the finite-set cumulant. This prevents factorial conventions from being rediscovered inside each physical specialization. Its recurrence-based route deliberately avoided depending on the then-unavailable closed Möbius formula; normalization and the exclusion of degree zero are explicit hypotheses, not implicit diagram conventions.

[Issue #436](https://github.com/naoki-cpp/LeanCondensedMatter/issues/436) later completed the independent explicit-coefficient layer: the nonempty bottom-to-top partition-lattice coefficient is `(-1)^(k-1)(k-1)!`, the empty lattice has value one, and the interval formula follows by applying the existing refinement-product factorization. Thus generic inversion and moment–cumulant proofs remain usable without expanding the coefficients, while consumers that need a closed form can use the dedicated partition module.

[Issue #290](https://github.com/naoki-cpp/LeanCondensedMatter/issues/290) made the next boundary an instantiation of an abstract connected-diagram theorem: supply decomposition and weight-factorization proofs, identify the diagram moment with the Dyson moment, and obtain the connected contribution. This supports a generic combinatorial theorem with a concrete physical adapter. Its historical `WeightedDiagramFamily` packaging is not a requirement to restore that name; current normalized moment and multiplicative-weight APIs remain authoritative. The nonempty vertex-set condition is a mathematical boundary, not an implementation detail.

[Issue #285](https://github.com/naoki-cpp/LeanCondensedMatter/issues/285) identifies the interface between combinatorial components and physical amplitudes: component-local order sums and shuffle integrals combine with pointwise contraction factorization and the scalar prefactor. The full amplitude factorization must carry all of these ingredients; graph connectivity alone does not establish multiplicativity of a physical weight. Keeping that proof in the statistics-specific layer lets the generic connected-decomposition theorem consume a justified multiplicative weight.

[Issue #276](https://github.com/naoki-cpp/LeanCondensedMatter/issues/276) explicitly kept sign, crossing-count, factorial, coupling, and amplitude conventions fixed while restructuring the transport API. The reason for the cleanup was composability with component ordering and simplex integration, not a change to the physical expansion. This separates a representation refactor from a mathematical convention change, which would require its own justification and downstream migration.

[Issue #273](https://github.com/naoki-cpp/LeanCondensedMatter/issues/273) extends that principle to crossing transport: use embeddings when only a subset of global crossings comes from one component, rather than claiming a global equivalence. An embedding retains injectivity for finite-set mapping and cardinality arguments; inter-component crossings remain a separate contribution.

[Issue #272](https://github.com/naoki-cpp/LeanCondensedMatter/issues/272) makes the pair-transport construction structural: start from the equivalence on ordered legs and restrict its pair-level form to matching membership predicates. The compatibility proof is the mathematical obligation; manually proving a fresh endpoint-by-endpoint bijection duplicates information already supplied by the ambient equivalence.

[Issue #271](https://github.com/naoki-cpp/LeanCondensedMatter/issues/271) explains why a component's ordered-leg map should be an `OrderEmbedding`, not a plain function accompanied by separately routed injectivity and monotonicity proofs. Crossing transport needs both preservation and reflection of endpoint order. Bundling that structure makes the required invariant available at every consumer and avoids reconstructing it through coordinate arithmetic.

[Issue #259](https://github.com/naoki-cpp/LeanCondensedMatter/issues/259) explains why diagrammatic data should carry canonical pair membership in its type. Representing crossing data through normalized pairs permits product equivalences and subtype restriction to transport it; raw coordinates plus repeated membership conjunctions force each consumer to reconstruct the same invariants. This is a representation rationale, not a requirement to preserve the issue's historical helper names or optional compatibility equivalence.

[PR #5](https://github.com/naoki-cpp/LeanCondensedMatter/pull/5) separated abstract Möbius inversion from computing the partition lattice's closed-form Möbius coefficients. The abstract moment–cumulant argument could use Mathlib's incidence-algebra Möbius function before the closed-form formula was available. Issue #436 later supplied that formula in a dedicated partition module; the reusable inversion layer still does not require consumers to wait for or expand a particular explicit evaluation. The PR's then-open proof gaps are not current proof-status claims.
